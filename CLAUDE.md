# Инструкции для Claude (исполнитель)

## Д-93: ветка → draft PR в тот же день
- Каждая ветка Claude в тот же день становится **draft PR**.
- PR связан со своей issue (`Refs #N` в описании), имеет exec-метку (`exec:claude`) и срок ready-to-merge.
- Issue без исполнителя и срока не считается назначенной.

## Общие правила
- Работа только через новую ветку и PR. Никогда не мержить, не пушить в master, не менять секреты.
- Ревью и мерж — MOS Tech после зелёного CI и его PASS (метка `review:mostech`).
- Лог pytest прикладывать к описанию PR; HANDOFF.md обновлять при каждом коммите.

## Git: обновление ветки
- Обновлять свою ветку PR от master (merge master в ветку) можно; мержить в master нельзя.

## Handoff по задачам
- Handoff ведётся по задачам: `docs/handoff/<issue>.md` (один файл на issue). `HANDOFF.md` — только индекс со ссылками, подробности в него не писать.
- При каждом коммите обновлять файл своей задачи; новую задачу добавлять в индекс.
