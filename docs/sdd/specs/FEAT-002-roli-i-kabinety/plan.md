## 1. Цель и объём реализации

**Цель:** общая шапка, меню и стартовая страница по роли; кабинеты по варианту А (4) или Б (7) — после Q-B1.

**Входит:** шапка; меню; стартовые страницы; страница «в разработке» для ролей без маршрутов; тесты «роль × пункт».

**Не входит:** новые бизнес-функции кабинетов; изменение прав; изменение схемы; вход (FEAT-001); анкета (FEAT-003); админ-панель (FEAT-004).

**Исходные требования:** FR-001…FR-007, NFR-001…005, AC-001…007.

**Предпосылки:** вход работает (FEAT-001, хотя бы на тестовом окружении).

## 2. Текущее состояние системы (As-Is)

- **Затрагиваемые подсистемы:** главная страница и шаблон (`app.py:317-320`, `templates/index.html`), роли (`auth_store.py:14-18`), RBAC (`auth.py:128-189`), блюпринты: `fund_view` (`/fund`), `portfolio` (`/portfolio`), `s5_monitor` (`/s5`), `s6_perimeter` (`/s6`), `s3_expert` (`/s3`), `s2_mandate` (`/s2`), `s1_intake` (`/s1`).

- **«Сообщить о проблеме»:** плавающая кнопка в `index.html:164-185`; адрес `/s1/feedback` (`s1_intake/main.py:934-956`), доступен любой роли (`app.py:766-767`).

## 3. Целевая архитектура (To-Be)

**Схема:** `Вход → GET / → определить роли (auth.current_user) → кабинет роли (шапка + меню + контент)`.

| Компонент | Ответственность | Изменение | Взаимодействия |
|---|---|---|---|
| Общий шаблон шапки `_header.html` (ПРЕДЛОЖЕНО) | имя, роль, «Выйти», «Сообщить» | Новый | `index.html`, страницы кабинетов |
| Таблица меню (код) | роль → пункты (только из `ACCESS_MATRIX.md`) | Новый | шаблоны |
| `GET /` | выбор стартовой страницы | Изменить (через `app.py` — **высокий риск**) | `auth.current_user` |
| Страница «Кабинет в разработке» | роли без маршрутов | Новый | шапка |
| `index.html` | кабинет основателя (форма) | Изменить: вынести шапку | FEAT-003 |

**Поток:** запрос `/` → `require_role(ANY_ROLE)` (`app.py:318`) → роль(и) → шаблон.

**Принципы:** меню — отражение прав, не источник прав; источник прав — `require_role`.

## 5. Контракты и интерфейсы

- `GET /` — тип REST/HTML; потребитель — браузер; вход — сессия; выход — HTML; авторизация — любая роль. **Адрес не менять.**
