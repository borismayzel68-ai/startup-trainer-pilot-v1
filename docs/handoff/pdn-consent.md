## Сделано
- `GET/POST /consent`, `POST /consent/revoke`. Чекбокс не отмечен. Без него заявка S1 и вход инвестора — 400, OAuth не начинается.
- Журнал `pdn_consents`: email, версия `v0-draft`, время UTC, IP, `revoked_at`, форма (`s1_intake` / `investor_login`).
- Миграция `db/migrations/006_pdn_consent.sql`. Номер 006 идёт после PR `fix/migration-005-fund-view` (там `004_fund_view` → `005`). От объектов 004/005 не зависит. Если на master уже есть 005, файл всё равно 006.
- Текст — `pdn_consent/text_v0-draft.txt`. Название и email для отзыва — `CONSENT_PROJECT_NAME` и `CONSENT_CONTACT_EMAIL`; пусто → плейсхолдеры `[Название проекта]` и `[email]`.
- Плашка «Черновик — юрист проверит». Отзыв ставит `revoked_at` на все действующие строки этого email.
- Вход инвестора: без неотзванного согласия сессия уходит на `/consent`. На callback email Google должен совпасть с email согласия, иначе 403 и пользователь не создаётся. Отзыв до callback — 403.
- На staging `/consent` открыт без сессии (согласие до входа). Наружу ничего не отправляется.
