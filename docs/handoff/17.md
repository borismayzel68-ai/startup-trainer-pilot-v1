## Сверка с master (29.10)

- нет пройденного периметра → **403** `blocked: true` для owner, fund_staff и admin-токена, запись `s6.gate` / `deny` в `audit_log` (и журнал `s1_approvals`);
- исключение только если именной человек записал `s6.human_waiver` / `allow` в аудит-лог на тот же хеш данных. Admin-токен такое решение записать не может. Подмена `release` в хранилище допуск не даёт.
