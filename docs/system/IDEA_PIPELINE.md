# Конвейер идей

1. **Идея** — формулировка + сторона + ГПФ (какая рутина/боль снимается).
2. **Красная команда** — поиск слабых мест, юр- и репутационных рисков, нарушений решений 12.10.
3. **Синтез** — best practice + ТРИЗ + ценность клиента.
4. **Изменения по областям** — список правок; у каждой владелец и срок.
5. **Решение Бориса** — принять / отклонить / доработать. До решения ничего не внедряется и не отправляется наружу.
