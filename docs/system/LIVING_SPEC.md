### Доходность в дашбордах (дополнение 13.10, ILPA/IPEV)
Структура блока: 3–5 KPI сверху → тренд по кварталам → флаги → детализация. У **каждой цифры** — дата, источник и уровень E0–E4. Переоценка (NAV) — ежеквартально.

| Кабинет | KPI и детализация |
|---|---|
| Фонд Artgen | Вложено; текущая оценка (NAV); возвращено. TVPI, DPI, RVPI, IRR. Доход УК (management fee, carry) и расходы фонда — отдельными строками |
| Частный инвестор | Вложения по сделкам; MOIC, IRR; выплаты; ожидаемые выходы. Бумажная (нереализованная) и реализованная прибыль — раздельно |

Формулы (ILPA): DPI = возвращено / вложено; RVPI = NAV / вложено; TVPI = DPI + RVPI; MOIC по сделке = (реализовано + текущая оценка) / вложено; IRR — по датам потоков.
Конвертируемые займы: проценты и конвертация считаются и показываются отдельно.

Источники расчёта — без нового ручного ввода: условия входа, ежемесячные отчёты портфельных компаний, узел «Исход сделки» (DEAL_OUTCOME_NODE.md). Нет источника для цифры — показывается «E0 DATA GAP», а не оценка.
Условия фонда (fee, carry, расходы) — **E0 DATA GAP до мандата**; в синтетических данных помечаются как допущение. Только синтетические данные; ничего наружу. Показатели — факты и расчёт, не инвестсовет.

## 5. Решения Бориса 12.10
- Подача в фонд и обратная связь бесплатны навсегда; статус оплаты не виден в скоринге.
- Уведомления внутри MOS — не «письма»; внешние письма/Telegram отправляет только Борис.
- Значок: «Оценено Artgen Copilot, [дата], [объём оценки]» — до юрпроверки.
- Частным инвесторам — факты, DD-сводка, вопросы; без вывода «инвестировать/нет».
- Пороги портфеля: runway < 9 мес — красный; отклонение burn > 20% — флаг.
