- Работа только через новую ветку и PR; в master не пушить, не мерджить, секреты не менять.

- Только синтетические данные. Внешние письма/Telegram и отчёты основателям автоматически не отправляются — только Борис.
- Каждая задача проверяется по ГПФ стороны (LIVING_SPEC.md §1) и решениям 12.10 (§5).
- Новые идеи идут через IDEA_PIPELINE.md; решение принимает Борис.
- Пробелы в ТЗ фиксируются в PR явно, не додумываются.
