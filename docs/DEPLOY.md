## Только синтетика (до решения юриста по #68)
При `APP_ENV=staging` приложение при старте:
1. отказывается запускаться, если `STAGING_SYNTHETIC_ONLY` выключен (всё, кроме `true/1/yes/on`; не задан = `true`);
2. отказывается запускаться без модуля `auth` из MOS-1 (#61): собственного входа у staging нет;
3. подключается к `DATABASE_URL` и отказывается запускаться, если в `users` есть запись с `is_synthetic = false`, кроме email'ов из `AUTH_ALLOWLIST`
   (участники пилота входят через #61 и создаются самим входом). Признак синтетики — колонка `is_synthetic`, **не домен email**.
   Недоступная БД — тоже отказ; нет таблицы `users` (до миграций) — проверка проходит.

Ограничение: проверка охватывает таблицу `users`; в S1-таблицах признака синтетичности нет — вебхук Tilda на staging закрыт сессией.
