# Сверка обновления с паспортом входа — SYN-CO-1

- `field_a` [changed]: вход='x', обновление='y'
- `field_b` [missing_in_update]: вход=10, обновление=None
- `field_c` [not_in_passport]: вход='NEEDS_EVIDENCE', обновление=1

Синтетический пример. Поля паспорта (field_a…) условные: состав паспорта входа в задаче не задан (NEEDS_EVIDENCE, см. HANDOFF.md). Триггер: отметка нового раунда создаёт флаг «проверка частичного выхода»; вопросы компании — модель в системе, без отправки в мессенджер.
