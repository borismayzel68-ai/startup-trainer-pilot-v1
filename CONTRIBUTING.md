# Правила работы

- Одна задача = один issue = один executor label (`exec:claude` или `exec:mos`) = одна ветка.
- Коммит после каждого законченного шага.
- HANDOFF.md обновляется при каждом коммите.
- Слияние в основную ветку (master) только после: зелёных тестов, ревью GPT и проверки Руководителя бизнеса.
